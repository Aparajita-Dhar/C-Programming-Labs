
# Foundational C Programming Portfolio

This repository contains core implementations of foundational Computer Science principles written in C. It serves as an academic archive demonstrating understanding of procedural programming logic, syntax structure, and lower-level execution models.

## Core Modules Included

1. **`01_program_structure.c` (Syntax & Compilation)**
   * Explores standard structural entry points, preprocessor headers, and outlines the primary functional differences between compilers vs. interpreters.
2. **`02_data_types.c` (Data & Memory Layout)**
   * Covers basic primitives (`int`, `float`, `double`, `char`), structural formatting via specifiers, and evaluates actual byte sizes in memory using `sizeof()`.
3. **`03_control_statements.c` (Conditional Branching)**
   * Uses multi-tiered decision-making structures (`if-else if-else`) to direct variable application paths based on logic evaluation.
4. **`04_iteration_loops.c` (Automation & Repetition)**
   * Demonstrates task automation structures via count-controlled (`for`) and condition-controlled (`while`) looping operations.
5. **`05_arrays.c` (Linear Data Collections)**
   * Implements linear array structures, showing element allocation, index-based data extraction, and array tracking using iterative sweeps.
